◈NeuroFlowWorkflow builder · frontend foundation and implementation

NeuroFlow — visual workflow builder

I established the frontend foundation for a no-code workflow builder inside a healthcare SaaS platform, and implemented a substantial part of it. Staff design automated flows on a canvas: a trigger starts the flow, branches route it, and actions run.

I built the canvas on React Flow (xyflow), with custom node types, drag-and-drop, and a side panel to configure each node. Branches support first-match or all-match logic, with each condition shown on the canvas and an automatic “else” path. Validation marks problems on the canvas without interrupting editing, and a conversion layer turns the editor graph into the backend workflow format and back. I later added new trigger and action types.

◎GravyWorkAI phone interviews · Rails, React, React Native

GravyWork — AI phone interviews for workers

GravyWork staffs shifts with vetted hourly workers. I designed and built a separate AI service that runs automated phone interviews to assess workers’ skills, which reduces manual screening work for staff.

A worker calls in, hears each question as generated speech, and records an answer. Background jobs turn the answers into text and score them with an LLM, then a signed webhook sends the result to the main platform for admins to review. Around it I built the reliability and fairness tools: model settings kept in config, handling for late recordings, attempt lockouts, call audit logs, and admin health and re-score screens.

Across the wider product I worked on the Rails API, the React admin portal, and the React Native worker app, including worker earnings, real-time chat, preferred staffing pools, and SMS, email, and push lifecycle messaging.

◇RoverJob-market data · API, AI job matching, CRM integrations

Rover — job-market data platform

Rover collects job ads from major job boards across Australia and New Zealand, merges and enriches them, and delivers them to recruitment CRMs and through a job-search API for client companies. I have developed and maintained the platform since 2023.

I created and maintained the scrapers for each job board, and designed and built that job-search API in Rails. The pipeline runs on Rails, Sidekiq, and PostgreSQL, with an hourly merge that groups jobs by company, Elasticsearch search, and a rule-based industry classification step that leaves a value empty rather than guess. I built delivery integrations for Salesforce, Bullhorn, HubSpot, and RecruiterFlow, and I support the developers at client companies who build on the API.

For JobRover, an AI job-matching product, I built the frontend and the backend, including the connection to its matching engine and Stripe billing: subscriptions, invoices, webhook handling, refunds, and failed-payment handling. I also built the internal operations dashboard in Next.js, TypeScript, and AG Grid on Cloudflare Workers.

▤Field Reporting PlatformAd hoc report builder and data validation · live

Field Reporting Platform — report builder and data validation

For a field-reporting web app, I independently built two live features: an ad hoc reporting engine and an automated validation system.

Users build reports in a Vue editor. The server checks each report definition against a JSON Schema and compiles it into one parameterized, read-only SQL query with a time limit. Results respect each user’s existing data access, and reports can be saved, shared, and exported to CSV or Excel with spreadsheet-safe output.

Each submitted report also runs through background checks for spikes, repeats, outliers, and differences from peers, using statistics cached nightly. Checks can be set per country, and staff work through flagged results in a review hub.
